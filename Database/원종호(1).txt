1. SQL(Query)문이란?
 데이터베이스에게 어떠한 행위를 하도록 요청하는 명령문이다.


2.DML, DCL, DDL에 대해서 설명하시오
DML은 데이터 조작어로 insert,select,update,delete가 있고 DCL은 데이터 정의어로 create,alter,dorp,rename가 있으며 DDL은 데이터 제어어로 grant,revoke가 있다.


3.OracleDB 자료형의 종류를 서술하세요
숫자를 저장하기 위한 자료형 number, 날짜와 시간 데이터를 저장하기 위한 자료형 date, 문자(문장)데이터를 저장하기위한 자료형으로 char,varchar2,CLOB이 있다, 이중 CLOB은 대용량의 문장을 저장하기 위하여 사용된다.


4.LIKE에 대해서 설명하시오 
like 연산자는 유사검색으로 사용자가 지정한 문자형태와 일치 또는 포함하고있는 자원을 검색하기 위하여 사용하며 % 는 모든 값, _ : 하나의 값을 표현하며 예시로 'a%'는 로 시작하는 모든자원을, '%a'는  a로 끝나는 모든자원, '%a%'은 어디든 a를 포함한 모든자원을 말하며, 'a____'은 a로 시작하는 5자리의 자원을 의미한다.


5.IN과 BETWEEN의 차이를 설명하시오
 in연산자는 주어진 목록에서 찿고자 하는 값이 있는 경우에 사용하며 or연산 Query를 간소화 할 수 있다. 반면 between연산자는 A와 B사이의 값을 조회하고자 할 때 사용하는 연산자이다.


6.id,pwd,name,email,phone을 작성하는 회원테이블(member_t)를 만드는 Query를 작성
단, id는 기본키로 지정하도록 하며 pwd와 name은 null값을 허용하지 않도록 한다.
create table MEMBER_T( 
		id NUMBER(5) primary key,
		name VARCHAR2(50) not null
		email VARCHAR2(50) not null
		phone NUMBER(20)
  );


7.모든 사원의 사번, 이름, 월급, 연봉을 출력
select employee_id,
	first_name,
	salary,
	salary* 12
from employees;


8.실월급 = 월급 + 월급 * 보너스라고 할 때  사번, 이름, 실연봉 순으로 조회
select employee_id,
	first_name,
	salary +  salary * nvl( commission_pct,0)	
from employees;
